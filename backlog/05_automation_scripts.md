# Вертикаль: Скрипты автоматизации и CLI-утилиты (Разработка и улучшение)

## Задача 1. Реализация приоритетной сортировки контента в утилите дампа проекта (Data-First Context Stack)
* Описание: Модернизация логики работы утилиты `dump_project` (.ps1 и .sh) для принудительной приоритезации критически важных файлов в начале результирующего дампа на основе внешнего конфигурационного файла. Это предотвратит эффект «потери в середине» (Lost in the Middle) у ИИ-моделей при анализе кода.
* Подзадачи:
    - [ ] Создать в каталоге утилиты (`scripts/dump_project/`) конфигурационный файл сортировки (например, `.dumpsort`), в котором построчно указать маски путей в порядке их приоритета: сначала правила проекта, затем доменные модели прикладного ядра.
    - [ ] Модернизировать код обеих версий скрипта (`dump_project.ps1` и `dump_project.sh`):
        - Реализовать чтение и парсинг файла `.dumpsort` из текущей папки скрипта.
        - Обеспечить первоочередную выгрузку и запись в итоговый файл тех директорий и файлов, которые соответствуют указанному в файле порядку приоритетов.
        - Настроить логику так, чтобы весь оставшийся код проекта, не упомянутый в конфигурации сортировки, выгружался следом в стандартном порядке по умолчанию.
    - [ ] Сформировать эталонное наполнение файла `.dumpsort` для текущей структуры проекта, распределив приоритеты так, чтобы правила проекта и доменные модели выгружались первыми, а инфраструктурные модули (SDK), бэкенд-серверы и клиентские приложения (apps) — в самом конце дампа.
