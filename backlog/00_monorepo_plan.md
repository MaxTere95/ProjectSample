# Архитектурный план: Глобальная реструктуризация папок (Product-First)

## Задача 1. Изоляция прикладных слоев продукта
* Описание: Создание папок-контейнеров на уровне файловой системы для группировки бизнес-логики вокруг конкретного продукта.
* Подзадачи:
    - [ ] Создать корневую директорию `shared/[имя_продукта]/` (например, `shared/sample/`).
    - [ ] Перенести все прикладные модули фронтенда в директорию `shared/[имя_продукта]/client/*`.
    - [ ] Перенести все прикладные модули бэкенда в директорию `shared/[имя_продукта]/server/*`.
    - [ ] Сформировать следующую структуру shared-слоя проекта:
        - `shared/common/core` (Глобальные модели данных для клиента и сервера)
        - `shared/[имя_продукта]/client/*` (Базы данных, репозитории, UI компоненты, экраны и DI хабы фронтенда)
        - `shared/[имя_продукта]/server/*` (Модули бизнес-логики Ktor и Spring серверов)

## Задача 2. Оптимизация структуры точек запуска приложений
* Описание: Реорганизация директории исполняемых модулей с разделением клиентских платформ и бэкенд-серверов под конкретный продукт.
* Подзадачи:
    - [ ] Перенести все исполняемые модули запуска в структуру `apps/[имя_продукта]/` (например, `apps/sample/`).
    - [ ] Сформировать следующую структуру apps-слоя проекта:
        - `apps/[имя_продукта]/client/*` (Модули сборки и запуска приложений для платформ)
        - `apps/[имя_продукта]/server/*` (Модули сборки и запуска серверов)

## Задача 3. Обновление билд-графа в файле настроек
* Описание: Перевод typesafe-аксессоров проектов на новые сгенерированные пути сборщика после перемещения папок.
* Подзадачи:
    - [ ] Обновить функции `includeClientShared()`, `includeServerShared()` и `includeServer()` внутри `settings.gradle.kts`.
    - [ ] Перевести typesafe-аксессоры в зависимых модулях `build.gradle.kts` на новый обобщенный формат в нижнем регистре по шаблонам:
        - `projects.shared.[имя_продукта].client.[подмодуль]` (примеры: `projects.shared.sample.client.ui`, `projects.shared.sample.client.data.database.core`)
        - `projects.shared.[имя_продукта].server.[модуль_сборки_сервера]` (пример: `projects.shared.sample.server.ktorExposed`)
        - `projects.apps.[имя_продукта].client.[модуль_сборки_клиента]` (пример: `projects.apps.sample.client.android`)
        - `projects.apps.[имя_продукта].server.[модуль_сборки_сервера]` (пример: `projects.apps.sample.server.springExposed`)
