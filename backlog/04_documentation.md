# Вертикаль: Документация, лицензирование и стандартизация

## Задача 1. Создание базы знаний для ИИ-ассистентов (AI Context Pack)
* Описание: Разработка специализированных инструкций и правил архитектуры для обеспечения корректной генерации кода нейросетями (Cursor, Copilot, ChatGPT).
* Подзадачи:
  - [ ] Создать в корне проекта директорию `.ai/`.
  - [ ] Создать файл `.ai/architecture_rules.md` с описанием билд-графа Gradle, типов путей typesafe-аксессоров и принципа Clean Architecture шаблона (SDK -> Shared -> Apps).
  - [ ] Создать файл `.ai/code_style.md` с жестким запретом на inline-комментарии справа от кода, требованиями к вынесению комментариев строго отдельной строчкой сверху и правилами именования функций.
  - [ ] Создать файл `.ai/tech_stack.md` со спецификацией используемых технологий (Decompose навигация, реактивные потоки Flow, Ktor Client, типы серверов).

## Задача 2. Создание технического руководства (README.md)
* Описание: Разработка главного руководства по развертыванию, кастомизации и использованию универсального KMP-шаблона.
* Подзадачи:
  - [ ] Написать техническое описание слоев архитектуры (системный SDK, прикладной Shared для клиента и серверов, модули сборки и запуска приложений (apps) и серверов (servers)).
  - [ ] Составить пошаговую инструкцию по замене демонстрационного модуля калькулятора на собственную бизнес-логику.
  - [ ] Добавить команды CLI для сборки клиентских платформ (Android, JVM Desktop) и запуска четырех бэкенд-серверов.

## Задача 3. Настройка двойного лицензирования и стандартов SPDX
* Описание: Юридическое оформление кодовой базы с интеграцией машиночитаемых стандартов идентификации лицензий.
* Подзадачи:
  - [ ] Создать файл `UNLICENSE` в корне проекта со стандартным текстом отказа от авторских прав.
  - [ ] Создать файл `LICENSE-MIT` в корне проекта со стандартным текстом лицензии MIT.
  - [ ] Добавить текстовый заголовок `// SPDX-License-Identifier: MIT OR Unlicense` в первую строку каждого исходного Kotlin-файла.
  - [ ] Добавить раздел в `README.md` с указанием выражения SPDX: `SPDX-License-Identifier: MIT OR Unlicense`.

## Задача 7. Документирование скриптов автоматизации проекта
* Описание: Разработка руководства по использованию, назначению и кастомизации встроенных CLI-скриптов автоматизации.
* Подзадачи:
  - [ ] Добавить инструкцию по запуску PowerShell скриптов `.ps1` на операционной системе Windows.
  - [ ] Добавить инструкцию по выдаче прав `chmod +x` и запуску Bash скриптов `.sh` на операционных системах macOS и Linux.
  - [ ] Описать синтаксис и назначение конфигурационного файла `.dumpignore` для фильтрации генерируемых дампов проекта.
  - [ ] Добавить раздел в `README.md` с подробным описанием существующих утилит:
    - `dump_project` — сканирует структуру репозитория, отсекает бинарные кэши `build/`, `.gradle/`, `.idea/` на основе правил из `.dumpignore` и собирает весь исходный код проекта в один текстовый файл для проведения сквозного аудита архитектуры.
    - `dump_gradle_config` — изолированно собирает только файлы конфигурации сборщика (`build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `libs.versions.toml`), позволяя быстро верифицировать билд-граф, плагины и иерархию зависимостей без анализа исходного кода фич.
